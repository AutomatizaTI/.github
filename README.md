### Reglas Básicas de Trabajo
* **Ramas:** Todo desarrollo parte desde `develop` mediante Pull Request hacia `main`.
* **Documentación:** Cada repositorio debe incluir su propio `README.md` con instrucciones de despliegue local.
* **Seguridad:** Prohibido subir credenciales, certificados SSL o archivos `.env` al código fuente.
